# Numi — Math Adventure

A responsive, browser-based math learning game for learners from early elementary school through high school. The app is a self-contained HTML file with no build step or external runtime dependencies.

## Run it

Open `index.html` in a modern web browser. XP is saved in the browser's local storage.

## What’s included

- Topic paths for number sense, arithmetic, multiplication, fractions, percentages, pre-algebra, algebra, geometry, trigonometry, statistics, and calculus
- Topic filters grouped by learner level
- Five-question practice rounds with answer feedback and score summaries
- XP rewards and a progress dashboard
- Responsive layouts for desktop and mobile screens
